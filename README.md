# Prática 3/4 - Sistema de Cadastro de Treinos

Aplicação web desenvolvida em React para cadastro, listagem e organização de treinos, como atividade da disciplina de Tecnologias Web.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- React Router DOM
- Context API
- CSS
- json-server
- localStorage
- Git e GitHub

## Funcionalidades

- Navegação entre páginas
- Página inicial com apresentação do sistema
- Cadastro de treinos
- Validação de formulário
- Listagem dinâmica dos treinos cadastrados
- Organização dos treinos por dia da semana
- Exclusão de treinos
- Persistência dos dados com localStorage
- Consumo de API REST local com json-server
- Interface responsiva
